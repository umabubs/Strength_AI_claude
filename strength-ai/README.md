# My Strength AI (experimental)

A separate, experimental copy of Strength Log 4.0 with a new **Scan** tab:

1. **Scan a machine**: take a photo and get a suggested machine name, with up to two alternatives and how sure it is.
2. **Learn the machine**: reviewed setup steps, how to do each exercise on it, the muscles it works, safety points and the animated demo.
3. **Add to today's workout**: one tap adds the exercise to the workout open on the Today tab, under "Added from Scan". It's saved with the workout when you finish.

It recognises 26 kinds of gym equipment: 17 that match exercises in your plan, and 9 more (chest press, pec deck, Smith machine, rower and so on) as guides only.

**Your stable Strength Log is not touched.** This app has its own storage, its own offline cache and its own Home Screen icon (with an "AI" badge). To bring your log across, use **Settings → Copy my log from Strength Log** (works in the same browser), or save a backup in Strength Log and use **Restore** here.

## Put it online (GitHub Pages)

1. On GitHub, create a new **public** repository called `strength-ai`.
2. Upload the contents of this folder (`index.html`, `sw.js`, `manifest.webmanifest`, `img/`, `icons/` and the rest) to the top level of the repository.
3. **Settings → Pages → Deploy from a branch → main / (root) → Save.**
4. After a minute or two it's live at `https://umabubs.github.io/strength-ai/`.
5. Open it in Safari, then **Share → Add to Home Screen**.

Without the recognition service below, Scan still works: you take the photo, then pick the machine from a picture list.

## Turn on automatic recognition (Cloudflare Worker)

Photos are identified by Claude through a small relay that keeps your API key secret. It runs on Cloudflare's free plan. The file is `worker/worker.js` in the zip (don't upload the `worker` folder to GitHub).

1. **Get an API key.** Sign in at console.anthropic.com, add some credit, and create an API key. Under limits, set a low monthly spend limit (for example $5).
2. **Create the Worker.** Sign up at dash.cloudflare.com. Go to **Workers & Pages → Create → Create Worker**, name it `my-strength-ai`, and deploy the starter.
3. **Paste the code.** Choose **Edit code**, replace everything with the contents of `worker.js`, and **Deploy**.
4. **Add the key as a secret.** In the Worker's **Settings → Variables and Secrets**, add a **Secret** named `ANTHROPIC_API_KEY` with your key.
5. **Optional, recommended: a daily limit.** Under **Storage & Databases → KV**, create a namespace (for example `strength-ai-limits`). In the Worker's **Settings → Bindings**, add a **KV namespace** binding with the variable name `LIMITS`. Each network address then gets 40 scans a day. Change it with a variable called `DAILY_LIMIT`.
6. **Connect the app.** Copy the Worker's address (it ends in `.workers.dev`), open My Strength AI → **Settings → Machine recognition**, paste it and tap **Save**.

The relay only answers requests from `https://umabubs.github.io`. To allow another site, add a variable `ALLOWED_ORIGINS` with a comma-separated list. It uses Claude Haiku by default; set a variable `MODEL` to change it.

**Cost:** each scan sends one small photo (about 150 KB) and gets a short answer back, which costs a fraction of a penny. Check the current API prices before you share the app widely.

## Privacy

- Photos are shrunk on the phone, sent to identify the machine, and not stored by the app or the relay.
- The relay returns only a machine name from the reviewed list. All setup and technique advice is written in advance, not generated by the AI.
- Ask people not to photograph other gym users.

## Notes

- Suggestions can be wrong. The app always shows what it thinks it saw and lets you pick another machine.
- Machines vary between brands. The guides tell you to follow the machine's own instruction label too.
- If the app looks out of date, use Strength Log's **Repair** page, or clear this site's data in Safari settings (back up first).
